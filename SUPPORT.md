# Support

Support expectations vary by repository and maturity level.

- Use a repository issue for reproducible bugs and documentation problems.
- Use repository discussions, when enabled, for questions and ideas.
- Use the private route in [SECURITY.md](SECURITY.md) for vulnerabilities.
- Visit [certiv.ai/company](https://certiv.ai/company/) for product and company
  contact information.

Certiv Labs projects state their maturity and maintenance level in the
[tools catalog](https://certiv.ai/tools/). A Lab or Beta label does not imply a
production support commitment.
