# Organization-profile publication checklist

- [ ] `Certiv-ai/certiv-labs` exists and its public README links resolve.
- [ ] `https://certiv.ai/tools/` and the first tool pages are live.
- [ ] The organization owner approves the profile language.
- [ ] A private security and conduct reporting route is approved.
- [ ] Default issue labels referenced by templates exist where needed.
- [ ] Organization website, description, email, and location are reviewed.
- [ ] `certiv-labs` and other maintained public projects are pinned.
- [ ] The `certiv.ai` domain is verified in GitHub organization settings.
- [ ] Repository visibility controls and member public-repository permissions
      are reviewed.
- [ ] `python3 scripts/check_docs.py` passes.
