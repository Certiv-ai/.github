# Governance

Certiv maintains organization-owned repositories.

Each public project should identify:

- at least one accountable maintainer;
- its maturity and support level;
- how release decisions are made;
- how security findings are handled;
- whether external contributions are currently accepted.

Maintainers are responsible for technical direction, release quality,
dependency review, issue triage, and applying the project's contribution and
security policies consistently.

Material changes to licensing, data handling, network access, security posture,
or project scope require Certiv approval before release.
